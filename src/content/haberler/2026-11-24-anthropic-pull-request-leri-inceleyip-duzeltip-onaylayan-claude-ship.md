Anthropic, yazılım mühendislerinin kodu daha hızlı yayına almasına yardım eden Claude Ship adlı yeni ürününü duyurdu. The Verge'ün haberine göre Claude artık pull request'leri (koda yapılan değişiklik tekliflerini) inceleyebiliyor, düzeltebiliyor ve onaylayabiliyor.

Claude'un kod inceleme özelliği (Code Review) mart ayında duyurulmuş, ekim ayında genel kullanıma açılmıştı. Claude Ship ile bunun yanına PR Steward ve Claude Approvals adlı iki ajan ekleniyor. İkisi de bugünden itibaren beta aşamasında.

PR Steward, başarısız olan otomatik test (CI) kontrollerine, birleştirme çakışmalarına ve Code Review, başka inceleme araçları ya da ekip üyelerinden gelen geri bildirimlere müdahale ediyor. Ajan, neleri değiştirdiğini anlatan yorumlar bırakıyor.

Claude Approvals ise kurumun politikası izin veriyorsa rutin değişiklikleri onaylayabiliyor. Anthropic'e göre ekipler, onay kararında Code Review bulgularını ya da doğal dille tanımladıkları kendi sınıflandırıcılarını sinyal olarak kullandırabiliyor.

Claude Ship, Claude Team ve Enterprise müşterilerine açık ve GitHub üzerindeki depolarla çalışıyor.
