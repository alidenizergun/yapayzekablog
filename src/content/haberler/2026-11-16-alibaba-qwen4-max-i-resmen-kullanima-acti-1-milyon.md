Alibaba, geçen haftaki ön sürümün ardından yeni nesil amiral gemisi modeli Qwen4-Max'i resmen duyurdu. Şirket modelin mimarisini, değerlendirme sonuçlarını ve API fiyatlarını açıkladı. Ön sürüm 11 Kasım'da kullanıma açılmıştı.

Model, Mixture-of-Experts (uzmanlar karışımı) mimarisinde 2,4 trilyon toplam parametreye, yerel görsel anlama özelliğine ve 1 milyon token bağlam penceresine sahip. API fiyatı milyon token başına girdide 1,5 dolar, çıktıda 4,5 dolar.

Alibaba, modelin kendi Work360 testinde Qwen3.8-Max'i geride bıraktığını söylüyor. Şirkete göre ortalama görev maliyeti 4,43 dolardan 1,67 dolara düştü.

## Sıralamalar ve erişim

Alibaba'nın Qwen hesabı, modelin Code Arena WebDev'de 6. sırada olduğunu ve Qwen3.8-Max'e kıyasla 74 puan yükseldiğini paylaştı. Hesap ayrıca modelin Agent Arena'da Qwen3.8-Max'i yüzde 7,5 net farkla geçtiğini bildirdi. Model OpenRouter'da ve OpenCode Go'da kullanıma açıldı. Bu sonuçlar şirketin kendi açıklamalarına dayanıyor.

Alibaba, Qwen4-Max'in ağırlıklarını açmadı. Şirket, Qwen4 serisindeki daha küçük modellerin ileride açık kaynak olarak sunulacağını doğruladı.
