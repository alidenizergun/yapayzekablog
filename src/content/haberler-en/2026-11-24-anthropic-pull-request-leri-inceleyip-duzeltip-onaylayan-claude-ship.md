Anthropic has unveiled Claude Ship, a new product that helps software engineers ship code faster. According to The Verge, Claude can now review, fix and approve pull requests (proposed changes to code).

Claude's code review feature (Code Review) was announced in March and made generally available in October. With Claude Ship, two agents are being added alongside it: PR Steward and Claude Approvals. Both are in beta starting today.

PR Steward handles failing automated test (CI) checks, merge conflicts, and feedback from Code Review, other review tools or team members. The agent leaves comments explaining what it changed.

Claude Approvals can approve routine changes if the organization's policy allows it. According to Anthropic, teams can have the approval decision use Code Review findings or their own classifiers, defined in natural language, as signals.

Claude Ship is available to Claude Team and Enterprise customers and works with repositories on GitHub.
