Anthropic has made it possible to install Claude Artifacts as an app on Mac or Windows. The feature is in beta and requires the latest version of Claude for macOS or Windows. Users create an Artifact in a chat and can keep it in the dock without writing any code.

Installed apps can use operating system APIs, connectors and Claude itself. This allows them to add a menu bar item, create transparent windows and send notifications. Examples include a custom terminal, a file manager and a video editor.

According to Felix Rieseberg of Anthropic, writing on X, a Claude account and the Claude app are required for now, and a free account is enough. Those with an Apple Developer account can also have Claude build standalone apps.
